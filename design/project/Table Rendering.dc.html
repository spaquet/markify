2aTables — cell preview card

Rows keep a fixed height, so nothing moves. Hovering a row highlights it. Hovering a cell whose text is cut off brings up a floating glass card in place, showing the column name and the full text. Cells that already fit show no card. Compare with 1a, where the row itself grows.

1aTables — hover to expand

At rest, each cell shows one line and ends in an ellipsis if the text is cut off. Hovering a row (after a 120 ms pause, so moving the pointer across the table doesn't flicker) highlights it and grows it so every cell's full text wraps into view. Narrow columns such as numbers are sized to their content. Tweaks: expand the whole row or only the hovered cell.
