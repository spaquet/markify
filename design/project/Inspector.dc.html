4. Table of contents

Long documents need a live outline. Today the right panel lists headings, but there is no way to insert a table of contents into the document itself, and links to missing headings fail silently.

5. Capture web pages

Open URL reads remote Markdown files only. Users expect a clipper that turns any article into clean Markdown, as the Obsidian Web Clipper does.
