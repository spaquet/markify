Library search — built on Spotlight

One field, one scope picker. Markify donates one Spotlight item per note and asks Spotlight for matches; it never ranks or embeds anything itself. Results are grouped by where they live (Library, project, OKF bundle), and every row shows its relative path, so two README files are never confused. Exact matches show the line with the words highlighted and open at that line. Related results contain none of your words, so they open at the top of the note and never pretend to have a match location. The footer always says whether the index is finished, so “nothing found” and “not indexed yet” look different.
