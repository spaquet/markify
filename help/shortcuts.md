# Keyboard shortcuts

You can change most of these in **Settings › Shortcuts**.

## Editor

| Shortcut | Action |
| --- | --- |
| ⌘/ | Toggle the Markdown lens |
| ⌃⌘S | Show or hide the library |
| / | Insert a block (at the start of a line) |
| ⌘F | Find |
| ⌥⌘F | Find and replace |
| ⌘G / ⇧⌘G | Next / previous match |
| ⌘= / ⌘- | Zoom in / out |
| ⌘0 | Actual size |
| ⌘-click | Follow a link or footnote |
| Tab / ⇧Tab | Next / previous table cell |

## Formatting

| Shortcut | Action |
| --- | --- |
| ⌘B | Bold |
| ⌘I | Italic |
| ⇧⌘X | Strikethrough |
| ⌘E | Inline code |
| ⌘K | Link |
| ⌥⌘0 | Body |
| ⌥⌘1 | Title |
| ⌥⌘2 | Heading |
| ⌥⌘3 | Subheading |

## Tables

With the caret in a table cell:

| Shortcut | Action |
| --- | --- |
| ⌥⌘↑ / ⌥⌘↓ | Insert a row above / below |
| ⌥⌘← / ⌥⌘→ | Insert a column left / right |
| ⌥⌘⌫ | Delete the row |
| ⌥⇧⌘⌫ | Delete the column |

## Apple Intelligence

| Shortcut | Action |
| --- | --- |
| ⇧⌘W | Writing Tools for the selection |
| ⌘↩ | Generate or continue at the caret; press again to keep |

## Documents

| Shortcut | Action |
| --- | --- |
| ⌘N | New document |
| ⌘O | Open |
| ⇧⌘O | Open bundle folder |
| ⌘S | Save |
| ⌘, | Settings |
