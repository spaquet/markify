Markify Help

Markify is a Markdown editor for macOS 26 that shows your document on one page. Write on the rendered page, press ⌘/ to see the same text as plain Markdown, and press it again to come back. Nothing is converted: both views edit the same .md file.

New to Markify? Open the Welcome tour, a document that shows the main features by letting you try them.

Working with a coding agent? Read its Markdown reports in Markify.

Tip

In Markify, search this help from the Help menu: type a word such as “table” or “export” in its search field.
