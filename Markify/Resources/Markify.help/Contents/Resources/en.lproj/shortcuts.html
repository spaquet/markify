Markify Help

Keyboard shortcuts

You can change most of these in Settings › Shortcuts.

Editor

ShortcutAction
⌘/Toggle the Markdown lens
⌃⌘SShow or hide the library
/Insert a block (at the start of a line)
⌘FFind
⌥⌘FFind and replace
⌘G / ⇧⌘GNext / previous match
⌘= / ⌘-Zoom in / out
⌘0Actual size
⌘-clickFollow a link or footnote
Tab / ⇧TabNext / previous table cell

Formatting

ShortcutAction
⌘BBold
⌘IItalic
⇧⌘XStrikethrough
⌘EInline code
⌘KLink
⌥⌘0Body
⌥⌘1Title
⌥⌘2Heading
⌥⌘3Subheading

Tables

With the caret in a table cell:

ShortcutAction
⌥⌘↑ / ⌥⌘↓Insert a row above / below
⌥⌘← / ⌥⌘→Insert a column left / right
⌥⌘⌫Delete the row
⌥⇧⌘⌫Delete the column

Apple Intelligence

ShortcutAction
⇧⌘WWriting Tools for the selection
⌘↩Generate or continue at the caret; press again to keep
