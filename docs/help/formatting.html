Formatting

In an empty document, the caret matches the Untitled placeholder's title size. Once you start typing, it follows the text's font.

The format bar

Select text and a glass format bar appears above it with Writing Tools, the block style menu, bold, italic, strikethrough, code and link. It disappears on your next keystroke. In the Markdown lens, the same buttons wrap your selection in the right syntax.

ShortcutAction
⌘BBold
⌘IItalic
⇧⌘XStrikethrough
⌘EInline code
⌘KLink

Block styles

The block menu in the format bar (it shows the current style, such as Body ▾) changes every paragraph in the selection to a title, heading, subheading, body text, quote, code block, callout or list. Each row previews the style and shows its Markdown prefix.

ShortcutStyle
⌥⌘0Body
⌥⌘1Title (#)
⌥⌘2Heading (##)
⌥⌘3Subheading (###)

The slash menu

Type / at the start of a line to insert a block. Keep typing to filter the list (for example /tab for Table), use the arrow keys to choose, and press Return.

Lists and tables

  • Press Return in a list to continue it with the next bullet, number or checkbox; press Return on an empty item to end the list.
  • Numbered lists renumber themselves when you add, remove or move items.
  • To nest an item, indent it with spaces in the Markdown lens.
  • Click a task's checkbox to tick it; the file changes from - [ ] to - [x].
  • In a table, press Tab to move to the next cell and ⇧Tab to go back. Pressing Tab in the last cell adds a row.
  • To add or remove rows and columns, right-click a cell and choose Insert Row Above or Below, Insert Column Left or Right, Delete Row or Delete Column, or use their shortcuts (⌥⌘ with an arrow key, ⌥⌘⌫ and ⌥⇧⌘⌫). A row inserted above the header row becomes the new header, and deleting the header promotes the first row below it. A table keeps at least its header and one column.
