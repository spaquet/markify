Why Markify

The finished page and the plain file. At the same time.

Other editors make you choose: read raw syntax all day, or hand your words to an app that stores them its own way. Markify gives you both, without compromise.

01

A page, not a preview.

No split window, no second pane to keep in sync. Headings, tables, tasks, math and diagrams render where you type them, and the syntax steps out of the way.

02

Your file, untouched.

Every document is an ordinary .md file wherever you put it. Markify never converts or rewrites it, so Git diffs stay clean and every other tool reads exactly what you wrote.

03

Mac, all the way down.

SwiftUI and TextKit 2, Liquid Glass, autosave and versions. Math renders without a web view, and Apple Intelligence runs on your Mac, not on a server.

Use cases

One editor. Whatever you write.

Markify adapts to the work, from a README in a busy repository to a thesis full of equations.

Developers

Docs that live next to your code.

READMEs, design docs and changelogs stay in your repository as plain Markdown. Markify makes them pleasant to write and easy to check.

  • Open from GitHub or GitLab. Paste a file link, or browse a repository’s Markdown. Private repositories work with a personal access token.
  • Every link, checked. The Links inspector lists each destination with its line numbers and flags local files and web pages that don’t resolve.
  • Reports from your agents. The markify command and plugins for Claude Code, Codex and OpenCode open long answers on a real page.
  • Code, diagrams and MDX. Syntax colors, offline Mermaid, and MDX blocks kept exactly as written.

Students & researchers

Equations that typeset as you type.

Lecture notes, problem sets and papers with real math, in a file your supervisor, Pandoc or GitHub can open.

  • LaTeX, rendered natively. Inline $…$ and display $$…$$ math, typeset on your Mac. Click a formula to edit it.
  • Long documents, mapped. The Contents outline lists every heading; jump to one, or insert a table of contents.
  • Footnotes that behave. Hover a reference to read it; ⌘-click to jump there and back.
  • Hand in a PDF. Paginated export with vector math and diagrams, and page breaks that respect headings, tables and code.

Note keepers

A library of plain files.

Point Markify at a folder of notes and keep working with it. No import, no database, no lock-in.

  • Any folder is a library. Browse subfolders and filter notes by title, folder or preview, beside the files you opened from anywhere.
  • Link by dragging. Drop a note into a document to link it; ⌘-click to follow.
  • Knowledge bundles. Open Knowledge Format support with backlinks, status, trust signals and validation.
  • Quick Look in Finder. Press Space on a note to see it formatted, with images, math and diagrams.

Questions

Good to know.

Is Markify really free?

Yes, including for work. The source is on GitHub under MIT with the Commons Clause, which only restricts selling Markify itself or a product built substantially on it. Sponsorships keep new releases coming.

Which Mac do I need?

Any Mac with macOS 26 Tahoe or later, with Apple silicon or an Intel processor. The download button picks the right build for this Mac; the other one is always a click away. Apple Intelligence features need a supported Mac with Apple Intelligence turned on.

Will Markify change my Markdown?

No. Both lenses show the same text, so switching is a restyle, not a conversion. Markify writes back exactly what you typed, and other apps, Git and your site generator read the same file.

Can I search across my notes?

Yes. Press ⇧⌘F to search full Markdown note contents with Apple Spotlight. Scope results to your Library, a subfolder, a granted project or a knowledge bundle; exact matches open at their source location. Library search guide.

Is my writing sent anywhere?

Your documents stay in the files you choose. Apple Intelligence runs on device. Markify checks for updates, can load remote images if you allow it, and sends crash reports without document text. The privacy page lists every request.

macOS says it can’t verify Markify. Is that normal?

For now, yes: Markify isn’t notarized yet. The first time you open it, click Done, then choose Open Anyway in System Settings › Privacy & Security. The install guide shows each step.
