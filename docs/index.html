Powerful Features

Everything you need for seamless markdown editing on macOS

Live Preview

See your markdown rendered in real-time as you type. Watch your content come to life instantly.

Split-Pane Interface

View editor and preview side-by-side for the perfect balance between composition and visualization.

MDX Support

Edit both standard Markdown and MDX files with full support for JSX components in markdown.

GitHub-Flavored Markdown

Full support for GitHub's markdown extensions including tables, strikethrough, and more.

Recent Files

Quick access to your recently edited documents right in the sidebar for fast navigation.

Insert Tools

Convenient buttons for inserting images, links, tasks, and lists with a single click.

Toggle Editor

Hide or show the editor pane with a single click to focus on preview or editing.

Auto-Save

Documents are automatically saved as you work, so you never lose a single change.

Apple Intelligence

Harness the power of Apple Intelligence to generate, refine, and polish your markdown text.
